🔒 Desabilitar Tracking Prevention

⚠️ Aviso: Firefox está bloqueando o acesso ao localStorage (armazenamento local) devido à Proteção Aprimorada contra Rastreamento.

Para localhost, siga os passos:

  1. Na barra de endereço, digite: about:config e pressione Enter
  2. Clique no botão "Aceitar o Risco e Continuar"
  3. Na caixa de pesquisa, procure por: privacy.trackingprotection.enabled
  4. Se estiver marcado como true, clique duas vezes para mudar para false
  5. Pesquise por: privacy.trackingprotection.pbmode.enabled
  6. Se estiver marcado como true, clique duas vezes para mudar para false
  7. Pesquise por: network.cookie.cookieBehavior
  8. Defina o valor como 0 (permitir todos os cookies)
  9. Recarregue a página
💡 Dica: Alternativamente, você pode desabilitar Tracking Prevention apenas para localhost:
1. Clique no ícone de escudo 🛡️ na barra de endereço
2. Clique em "Desabilitar proteção nesta página"
3. Recarregue
