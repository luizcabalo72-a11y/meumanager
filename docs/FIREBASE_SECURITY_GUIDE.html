# 🛡️ GUIA DE PROTEÇÃO: FIREBASE QUOTAS E ALERTAS ## ⚠️ URGENTE: Siga estes passos AGORA para proteger seu projeto --- ## 1️⃣ CONFIGURAR QUOTAS NO FIREBASE CONSOLE ### Acesse o Console 1. Vá para [console.firebase.google.com](https://console.firebase.google.com) 2. Selecione projeto: **meumanager-b02b0** 3. Vá para **Configurações do Projeto** (⚙️ Engrenagem) ### Limitar Operações de Firestore 4. Clique em **Quotas** (ou **Quotas and limits**) 5. Configure os seguintes limites: ``` ┌─────────────────────────────────────────┐ │ FIRESTORE QUOTAS │ ├─────────────────────────────────────────┤ │ • Leituras/minuto: 10.000 │ │ • Escritas/minuto: 5.000 │ │ • Deletions/minuto: 1.000 │ │ • Índices: 100 │ │ • Tamanho máx. doc: 1 MB │ │ • Tamanho máx. colecão: Ilimitado │ └─────────────────────────────────────────┘ ``` ### Limitar Cloud Functions 6. Clique em **Cloud Functions Quotas** 7. Configure: ``` ┌─────────────────────────────────────────┐ │ CLOUD FUNCTIONS QUOTAS │ ├─────────────────────────────────────────┤ │ • Invocações/segundo: 100 │ │ • Timeout: 60 segundos │ │ • Memória: 512 MB │ │ • CPU concorrente: 1 │ └─────────────────────────────────────────┘ ``` ### Limitar Authentication 8. Vá para **Authentication** > **Quotas** 9. Configure: ``` ┌─────────────────────────────────────────┐ │ AUTH QUOTAS │ ├─────────────────────────────────────────┤ │ • Sign-ups/hora: 100 │ │ • Sign-in attempts/IP/6h: 50 │ │ • Password reset/email/day: 3 │ └─────────────────────────────────────────┘ ``` --- ## 2️⃣ CONFIGURAR ALERTAS DE CUSTOS ### Google Cloud Budgets 1. Vá para [Google Cloud Console](https://console.cloud.google.com) 2. Navegue para **Billing** > **Budgets and alerts** 3. Clique em **Create Budget** ### Configure Alertas ``` Nome: Alerta Meu Manager Budget: R$ 100/mês (ajuste conforme necessário) Thresholds: • 50% do orçamento → Email de aviso • 100% do orçamento → Email crítico • 150% do orçamento → Email crítico Destinatários: seu_email@dominio.com ``` --- ## 3️⃣ MONITORAMENTO EM TEMPO REAL ### Google Cloud Monitoring 1. Em [console.cloud.google.com](https://console.cloud.google.com) 2. Navegue para **Monitoring** > **Dashboards** 3. Crie um dashboard com: ``` MÉTRICAS A MONITORAR: ┌────────────────────────────────────┐ │ Firestore │ ├────────────────────────────────────┤ │ ✅ Documento reads/sec │ │ ✅ Document writes/sec │ │ ✅ Document deletes/sec │ │ ✅ Latência (p99) │ │ ✅ Quota usage % │ └────────────────────────────────────┘ ┌────────────────────────────────────┐ │ Cloud Functions │ ├────────────────────────────────────┤ │ ✅ Execution count │ │ ✅ Execution times │ │ ✅ Errors │ │ ✅ Memory usage │ │ ✅ CPU usage │ └────────────────────────────────────┘ ┌────────────────────────────────────┐ │ Authentication │ ├────────────────────────────────────┤ │ ✅ Sign-ups/dia │ │ ✅ Sign-ins/dia │ │ ✅ Failed attempts │ └────────────────────────────────────┘ ``` --- ## 4️⃣ IMPLANTAÇÃO DE FIRESTORE RULES ### Baixe Firebase CLI ```bash # Windows PowerShell npm install -g firebase-tools firebase login ``` ### Implante as Rules ```bash # Na pasta do projeto firebase deploy --only firestore:rules ``` --- ## 5️⃣ DETECÇÃO DE ATAQUES ### Sinais de Alerta 🚨 Fique atento a: ``` ⚠️ PICOS ANORMAIS: • Leituras/segundo > 100 sem motivo • Escritas/segundo > 50 sem motivo • Cloud Functions invocações > 500/min • Erros 429 (Rate limited) frequentes • Requisições de IP's diferentes incomuns ⚠️ PADRÕES SUSPEITOS: • Buscas sem usuário autenticado • Deletions em massa • Scritaqs para colecões não esperadas • Requisições do exterior (se app é local) ``` ### Resposta a Ataque ``` 1. ⏹️ Bloquear IP na sua WAF (se houver) 2. 📊 Consultar logs no Monitoring 3. 🔐 Desabilitar Firestore temporariamente: - Console > Firestore > Desabilitar 4. 🛡️ Revisar Security Rules 5. 🔔 Contatar suporte Google Cloud ``` --- ## 6️⃣ CHECKLIST DE SEGURANÇA ``` ✅ IMPLEMENTADO: [ ] API Key removida do frontend [ ] Firestore Security Rules ativa [ ] Rate Limiting em Cloud Functions [ ] Quotas configuradas [ ] Alertas de custos ativa [ ] Monitoring ativa [ ] Backup automático habilitado [ ] Autenticação 2FA ativa (sua conta Google) ⏳ REVISAR REGULARMENTE: [ ] Logs de acesso (1x/semana) [ ] Custos de billing (1x/semana) [ ] Tentativas falhadas (diárias) [ ] Performance (diárias) ``` --- ## 7️⃣ CUSTOS ESTIMADOS (Com Proteção) ``` CENÁRIO TÍPICO: ┌──────────────────────────────────────┐ │ Uso Normal (100 usuários) │ ├──────────────────────────────────────┤ │ Authentication: R$ 0,00 │ │ Firestore: R$ 10-20 │ │ Cloud Functions: R$ 5-10 │ │ Storage: R$ 2-5 │ │ ───────────────────────────────── │ │ TOTAL/MÊS: R$ 20-50 │ └──────────────────────────────────────┘ COM ATAQUE (Se desprotegido): ┌──────────────────────────────────────┐ │ 1 hora de ataque DDoS: │ ├──────────────────────────────────────┤ │ Leituras: 10M x $0.06/1M = R$ 600 │ │ Escritas: 5M x $0.18/1M = R$ 900 │ │ Functions: 1M x $0.0000004 = R$ 400 │ │ ───────────────────────────────── │ │ DANO: Até R$ 2.000+ por hora! 😱 │ └──────────────────────────────────────┘ ``` --- ## 8️⃣ REFERÊNCIAS ### Google Cloud Documentation -
