# 🔐 GUIA COMPLETO: Configuração Segura de Credenciais ## ❌ O QUE NÃO FAZER ```javascript // ❌ NUNCA ASSIM: const STRIPE_KEY = "sk_live_123456..."; // Exposto no código const MP_TOKEN = "sua_token_aqui"; // Visível no Git const API_KEY = "abcdef..."; // Qualquer pessoa vê ``` **Riscos:** - 💰 Cobranças não autorizadas - 🔓 Acesso não autorizado - 📸 Vazamento em screenshots/documentação - 🚨 Histórico do Git expõe credenciais --- ## ✅ O QUE FAZER ### 1️⃣ Usar Variáveis de Ambiente (.env) ```bash # .env (NÃO COMMITE!) STRIPE_SECRET_KEY=sk_live_sua_chave_real_aqui MP_ACCESS_TOKEN=seu_token_real_aqui FIREBASE_PROJECT_ID=meumanager-b02b0 ``` ```javascript // ✅ CORRETO: const STRIPE_KEY = process.env.STRIPE_SECRET_KEY; const MP_TOKEN = process.env.MP_ACCESS_TOKEN; // Valida if (!STRIPE_KEY) { throw new Error("STRIPE_SECRET_KEY não configurado"); } ``` ### 2️⃣ Arquivo .gitignore Protege ``` # .gitignore .env .env.local .env.*.local *-firebase-adminsdk-*.json service-account-key.json ``` ### 3️⃣ Usar .env.example para Documentar ```bash # .env.example (COMMITE!) STRIPE_SECRET_KEY=sk_live_coloque_sua_chave_aqui MP_ACCESS_TOKEN=seu_token_aqui ``` --- ## 🛠️ SETUP LOCAL ### 1. Clone o Projeto ```bash git clone https://github.com/seu-usuario/meumanager.git cd meumanager ``` ### 2. Crie .env do .env.example ```bash # Windows copy .env.example .env # Linux/Mac cp .env.example .env ``` ### 3. Edite .env com Suas Credenciais ```bash # Use seu editor favorito code .env # VS Code vim .env # Vim nano .env # Nano ``` ### 4. Adicione Suas Chaves Reais ```env STRIPE_SECRET_KEY=sk_live_51234567890... MP_ACCESS_TOKEN=APP_12345... FIREBASE_PROJECT_ID=meumanager-b02b0 ``` ### 5. Instale Dependências ```bash npm install ``` ### 6. Teste ```bash npm test ``` --- ## 🚀 SETUP PRODUÇÃO (Google Cloud) ### 1. Google Cloud Secret Manager ```bash # Crie um secret para Stripe gcloud secrets create stripe-secret-key \ --replication-policy="automatic" \ --data-file=- <<< "sk_live_sua_chave_real" # Crie um secret para Mercado Pago gcloud secrets create mp-access-token \ --replication-policy="automatic" \ --data-file=- <<< "seu_token_real" # Crie um secret para Firebase gcloud secrets create firebase-service-account \ --replication-policy="automatic" \ --data-file=serviceAccountKey.json ``` ### 2. Configure Cloud Functions para Usar Secrets ```yaml # cloudfunctions.yaml apiVersion: cloudfunctions/v2 runtime: nodejs20 entrypoint: main secretEnvironmentVariables: - key: "STRIPE_SECRET_KEY" projectId: "meumanager-b02b0" secret: "stripe-secret-key" version: "latest" - key: "MP_ACCESS_TOKEN" projectId: "meumanager-b02b0" secret: "mp-access-token" version: "latest" ``` ### 3. Deploy ```bash firebase deploy --only functions ``` --- ## 🔄 ROTAÇÃO DE CREDENCIAIS ### Stripe 1. [Dashboard Stripe](https://dashboard.stripe.com/apikeys) 2. Clique em "Rotate Key" 3. Confirme a rotação 4. Atualize em `gcloud secrets update stripe-secret-key --data-file=-` 5. Deploy novamente ### Mercado Pago 1. [Painel MP](https://www.mercadopago.com.br/developers/panel) 2. Vá para "Credenciais" 3. Regenere token 4. Atualize em `gcloud secrets update mp-access-token --data-file=-` 5. Deploy novamente ### Firebase 1. [Google Cloud Console](https://console.cloud.google.com) 2. IAM & Admin > Service Accounts 3. Selecione service account 4. Crie nova chave 5. Atualize e redeploy --- ## 📋 CHECKLIST DE SEGURANÇA ``` ✅ CREDENCIAIS: [ ] .env adicionado ao .gitignore [ ] .env.example criado (sem valores reais) [ ] Nenhuma chave no código-fonte [ ] Variáveis de ambiente documentadas ✅ DESENVOLVIMENTO: [ ] npm install dotenv (se usar) [ ] .env criado localmente [ ] Testes passando [ ] Nenhum erro de chave faltante ✅ PRODUÇÃO: [ ] Secrets configurados no GCP [ ] Cloud Functions credenciadas [ ] Logs monitoram acesso [ ] Alertas configurados para abuso ✅ ROTINA: [ ] Rotação de credenciais a cada 90 dias [ ] Monitoramento de uso [ ] Alertas de cobranças ativas [ ] Auditoria de acesso ``` --- ## 🚨 EMERGENCY: Credencial Exposta ### Ações Imediatas: 1. **Revogue a Credencial** ```bash # Stripe https://dashboard.stripe.com/apikeys → Revoke # Mercado Pago Painel → Credenciais → Regenerar # Google Cloud gcloud secrets versions destroy LATEST ``` 2. **Crie Nova Credencial** ```bash gcloud secrets create stripe-secret-key-new ... ``` 3. **Atualize Cloud Functions** ```bash firebase deploy --only functions ``` 4. **Audit Logs** ```bash gcloud logging read \ "resource.type=cloud_function AND \ protoPayload.methodName=functions.list" \ --format=json ``` 5. **Notifique Provedor** - Stripe Support - Mercado Pago Support - Google Cloud Security --- ## 📚 REFERÊNCIAS ### Stripe - [Documentação](https://stripe.com/docs/keys) - [API Keys Security](https://stripe.com/docs/keys#protecting-api-keys) - [Best Practices](https://stripe.com/docs/security/overview) ### Mercado Pago - [Credenciais](https://www.mercadopago.com.br/developers/pt/guides/additional-resources/credentials) - [Segurança](https://www.mercadopago.com.br/developers/pt/guides/additional-resources/security) ### Google Cloud - [Secret Manager](https://cloud.google.com/secret-manager/docs) - [Best Practices](https://cloud.google.com/secret-manager/docs/best-practices) --- ## 🎯 RESUMO RÁPIDO | Local | Credencial | Seguro?
