🛠️ PASSO 3: Deploy Seguro com Firebase ### 1. Arquivo firebase.json (Configurar) ```json { "hosting": { "public": ".", "ignore": [ "firebase.json", "**/.*", "**/node_modules/**", "debug-*.html", "verificador-*.html", "teste-*.html", "test-*.html", "setup-multiplas.html", "functions/**", ".git/**", "README.md" ], "rewrites": [ { "source": "**", "destination": "/index.html" } ] }, "functions": { "source": "functions", "runtime": "nodejs20" } } ``` ### 2. Deploy Comando ```bash # Listar o que vai fazer deploy firebase deploy --dry-run # Fazer deploy (sem debug files) firebase deploy --only hosting # Fazer deploy com functions firebase deploy --only hosting,functions ``` --- ## 🛠️ PASSO 4: Validar Deploy ### Checklist Antes de Publicar ``` ✅ SEGURANÇA: [ ] Nenhuma apiKey no frontend [ ] Nenhum arquivo debug exposado [ ] .env não está commitado [ ] Credenciais de serviço protegidas [ ] Security Rules ativa ✅ PERFORMANCE: [ ] Scripts otimizados [ ] CSS minificado (optional) [ ] Imagens comprimidas [ ] Cache headers configurados ✅ FUNCIONALIDADE: [ ] Login funciona [ ] Dados carregam corretamente [ ] Payments funcionam [ ] Sem erros no console ✅ MONITORAMENTO: [ ] Google Analytics ativa [ ] Error tracking ativa [ ] Quotas monitoradas [ ] Alertas configurados ``` --- ## 📊 Estrutura Final Recomendada ``` meumanager/ ├── 📁 desenvolvimento/ │ ├── debug-empresas.html │ ├── debug-produtos.html │ ├── verificador-empresas.html │ ├── teste-*.html │ ├── test-*.html │ └── setup-multiplas.html │ ├── 📁 tests/ │ ├── configuracoes.test.js │ ├── integracao.test.js │ ├── relatorios.test.js │ └── jest.config.js │ ├── 📁 functions/ │ ├── index.js │ ├── rate-limiter.js │ ├── firebase-backend-config.js │ └── package.json │ ├── 📁 .firebase/ │ └── (ignorar no Git) │ ├── index.html ✅ ├── login.html ✅ ├── dashboard.html ✅ ├── [...outros arquivos] ✅ ├── style.css ✅ ├── script.js ✅ ├── firebase-config.js ✅ ├── firebase-secure.js ✅ ├── firestore.rules ✅ ├── firebase.json ✅ ├── .gitignore ✅ ├── .firebaserc ✅ ├── package.json ✅ └── README.md ✅ ``` --- ## 🚀 CI/CD PIPELINE (Recomendado) ### GitHub Actions (Exemplo) ```yaml name: Deploy Produção on: push: branches: [ main ] jobs: deploy: runs-on: ubuntu-latest steps: -
